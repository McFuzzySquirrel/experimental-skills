# Example Output Guidance

> Load when the user asks for an example artifact or quality bar.

Use a short, factual meeting record with a chronological summary and explicit tables for decisions, action items, and unresolved questions. Do not add a section merely to make the output look complete; omit empty sections when the conversation contains no qualifying items.

The example should demonstrate:

- Neutral participant labels when names are unavailable.
- `TBD` for an unnamed action owner.
- A rationale grounded in the conversation rather than invented context.
- Clear separation between a proposal and a confirmed decision.
